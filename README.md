# Virtual Eden — Releases  This repository hosts public release artifacts for **Virtual Eden**, a cross-platform life management app for couples.  > Source code: [sylvanas-labs/virtual-eden-flutter](https://github.com/sylvanas-labs/virtual-eden-flutter) (private)  ## Downloads  Go to the [Releases](../../releases) tab to download the latest version.  | Platform | File | Notes | |----------|------|-------| | Android | `app-release.apk` | Sideload — see install instructions below | | Windows | `VirtualEden-Setup.exe` | NSIS installer |  ## Release Tracks  | Track | Tag format | Description | |-------|-----------|-------------| | **Stable** | `v1.2.3` | Built from `main`. Recommended for most users. | | **Beta** | `v1.2.3-beta.N` | Built from `develop`. May contain incomplete features or bugs. |  ## Installing on Android  1. On your Android device, enable **Install unknown apps** for your browser or file manager (Settings → Apps → Special app access). 2. Download the latest `app-release.apk` from the [Releases](../../releases) tab. 3. Open the downloaded file and tap **Install**.  ## Auto-Update  The app checks this repository for updates automatically. When a new release is published, the app will prompt you to download and install it. No action is needed beyond tapping the prompt.  ## Installing on Windows  Run `VirtualEden-Setup.exe` and follow the installer prompts. The app installs to your user directory and does not require administrator privileges.
